# زیرنویس‌ساز

## اجرا
روی فایل «اجرا.bat» دوبار کلیک کنید. برنامه در مرورگر باز می‌شود: http://localhost:5178

نیازمندی‌ها: Node.js 18 یا جدیدتر، ffmpeg روی PATH، و Chrome یا Edge (برای ساخت خروجی MP4).

## مراحل کار
1. ⚙ تنظیمات API: کلیدهای Speechmatics، Deepgram و Gemini را وارد کنید. کلیدها در `data/config.json` ذخیره می‌شوند.
2. ویدیو را داخل برنامه بکشید و رها کنید، سرویس تبدیل گفتار به متن را انتخاب کنید و «ساخت زیرنویس» را بزنید.
3. متن هر خط را در زبانه‌ی «متن» اصلاح کنید. اگر زیرنویس جلوتر یا عقب‌تر از صداست، از «جابجایی زمان» استفاده کنید.
4. در زبانه‌ی «استایل» یکی از استایل‌های آماده را انتخاب و تغییر دهید. با «ذخیره به‌عنوان استایل من» می‌توانید آن را نگه دارید.
5. در زبانه‌ی «فونت‌ها» فایل‌های ttf، otf، woff یا woff2 را اضافه کنید. فونت‌ها در `data/fonts` ذخیره می‌شوند.
6. در زبانه‌ی «خروجی» ویدیوی MP4 با زیرنویس چسبیده را بسازید.

## ساختار
- `server.mjs`: سرور محلی؛ استخراج صدا با ffmpeg و ارسال آن به APIها، و ذخیره‌ی فونت‌ها و تنظیمات
- `public/render.js`: موتور رسم زیرنویس (پیش‌نمایش و خروجی از همین کد استفاده می‌کنند)
- `public/presets.js`: استایل‌های آماده
- `public/export.js`: ساخت MP4 داخل مرورگر با Mediabunny
